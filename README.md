# 현장조사 빠른입력기 (field-flora)

현장에서 **폰으로** 식물상·식생·훼손수목 조사를 기록하고 조사표 CSV로 내보내는 오프라인 웹앱.

산속·비행기모드에서도 100% 동작한다. 기록은 탭하는 즉시 저장되며 저장 버튼이 없다.

**배포 주소**: https://jeju-eco.github.io/field-flora/

## 기능

### 공통
- **종 검색 17,323종 내장** — 국명 / 학명 / 별칭 / 초성(`ㅅㄴㅁ` → 소나무)
- **전체 결과 + 더보기** — 25종씩 끊어 보여주고 `＋N종 더보기`로 펼친다 (`나무` 3,102종까지)
- **음성 입력** — 검색창·수목 시트의 🎤 버튼. 단 **인터넷 필요**(애플 서버 사용).
  오프라인에서는 키보드의 마이크(받아쓰기)를 쓰라고 안내한다
- **화면 꺼짐 방지** — 조사 중 장갑을 벗고 화면을 다시 켜지 않도록 Wake Lock 유지
- **완전 오프라인** — Service Worker로 앱·사전 전체 캐시, IndexedDB + localStorage 이중 저장

### 식물상 탭
- **탭 한 번에 추가, 다시 탭하면 취소** (개체수가 멋대로 늘지 않는다)
- 개체수·우점도를 입력해둔 종은 지울 때 확인을 거친다
- **우점도(Braun-Blanquet)** — r, +, 1~5. 미지정이면 `–`로 표시
- 추가 직후 토스트의 **[취소]** 버튼(4초)으로 오탭을 즉시 되돌린다
- 지점별 `N종 / M개체`와 출현종 이름을 한 줄로 나열

### 식생 탭 (방형구)
- 방형구별 **4층위**(교목 T1 / 아교목 T2 / 관목 S / 초본 H)
- 층위별 **식피율(%)·평균수고(m)**, 층위별 종·우점도
- 방형구 규격·경사·방위·해발, GPS 좌표 자동 기록
- 층위의 `＋종`을 누르면 식물상 탭으로 이동하며, **어느 방형구 어느 층에 넣는 중인지 배너로 계속 표시**

### 수목 탭 (훼손수목)
- 수종·**흉고직경·수고·수관폭·본수**·조치(존치/이식/벌채)
- 규격 표기(`H8.0×B25×W4.0`)와 경급(소경목~노거수급)이 입력 중 실시간 표시
- 장갑 낀 손으로 누를 수 있는 **큰 ± 스테퍼**(46×56px)
- 수목별 GPS 좌표 자동 기록

### 내보내기
| 버튼 | 내용 |
|---|---|
| 식물상 기록 | 지점·종·개체수·우점도·좌표 원장 |
| 식물상 조사표 | 지점×종 매트릭스, 과별 정렬, 지점별 출현종수 합계 |
| 식생조사표 | 방형구별 입지·층위별 식피율·층위별 종/우점도 |
| 훼손수목 조서 | 연번·규격·본수·조치·좌표 + **조치별 소계와 총 본수 자동 계산** |
| 백업 JSON | 전체 상태 (다른 기기 복원용) |

모두 BOM 포함 CSV라 엑셀에서 한글이 깨지지 않는다.
공유 → "Drive에 저장"으로 구글드라이브에 바로 올릴 수 있다.

## 폰에 설치 (아이폰)

1. Safari로 배포 주소 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행 — 주소창 없는 전체화면으로 뜬다

> 첫 실행은 **인터넷이 연결된 상태**에서 해야 사전(1.9MB)이 폰에 저장된다.
> 그 이후로는 오프라인에서 계속 쓸 수 있다.
>
> 앱을 갱신했는데 반영이 안 되면 **앱을 완전히 닫았다가(앱 전환창에서 위로 밀기) 다시 실행**한다.

안드로이드는 Chrome → 메뉴 → "홈 화면에 추가".

## 현장 사용 흐름

```
현장 도착 → [지점] GPS로 St.1 기록
         → [식물상] 종 검색해 탭 (잘못 눌렀으면 다시 탭하거나 [취소])
         → [식생] 방형구 추가 → 층위별 식피율 입력 → 층위마다 ＋종
         → [수목] 이식·벌채 대상 수목을 ± 버튼으로 규격 입력
         → 지점 이동은 상단 [＋]
         → [요약] 조사표 CSV 4종 내보내기 + 백업 JSON
```

## 데이터 안전

| 상황 | 결과 |
|---|---|
| 앱 강제 종료 | 기록 유지 (매 기록마다 즉시 저장) |
| 폰 재부팅 | 기록 유지 |
| 오프라인 | 정상 동작 |
| IndexedDB 응답 실패 | localStorage로 자동 대체 (내용이 많은 쪽을 채택) |
| Safari 캐시 삭제 | **데이터 소실** → 조사 후 CSV/백업 JSON을 꼭 내보낼 것 |

조사가 끝나면 **[요약] → 백업 JSON**을 드라이브에 함께 올려두면 다른 기기에서 그대로 복원된다.

## 개발

```bash
# 종 사전 재생성 (plant_atlas DB에서 추출)
python tools/build_dict.py [DB경로]

# 아이콘 재생성
python tools/make_icons.py

# 전체 테스트 (165개)
npm test

# 로컬 실행
npm run serve      # http://localhost:8777
```

### 테스트 구성

| 파일 | 개수 | 범위 |
|---|---|---|
| `core.test.js` | 30 | 검색·초성·집계·CSV 순수 로직 |
| `ui.test.js` | 63 | jsdom UI 통합 (추가/취소/저장/내보내기) |
| `css.test.js` | 9 | CSS 원문 검사 — `[hidden]` 충돌 회귀 방지 |
| `storage.test.js` | 11 | IndexedDB 실패 시 복원, 빈 조사 정리 |
| `more.test.js` | 4 | 검색 결과 더보기 페이징 |
| `field.test.js` | 48 | 현장 시나리오 — 방형구·훼손수목·음성·내보내기 |

### 구조

```
index.html        화면 구조 (5탭 + 시트 4종)
styles.css        모바일 UI (탭 타겟 최소 56px)
core.js           순수 로직 — 검색/집계/CSV (DOM 비의존, Node 테스트 가능)
app.js            DOM 바인딩 + IndexedDB 저장
sw.js             오프라인 캐시
data/taxa.json    종 사전 17,323종
icons/            앱 아이콘
tools/            사전·아이콘·샘플 생성기
tests/            테스트
samples/          실제 생성된 CSV 예시
```

`core.js`는 브라우저와 Node 양쪽에서 로드되며 DOM에 의존하지 않는다. 검색·집계·CSV 규칙을 바꿀 때는 여기만 수정하고 `tests/core.test.js`로 검증한다.

### 주의: CSS 테스트가 원문 검사인 이유

`styles.css`의 `.sheet{display:flex}`가 HTML `hidden` 속성을 덮어써 시트가 **투명한 전체화면 오버레이로 모든 터치를 가로채는** 버그가 있었다. `[hidden]`은 브라우저 기본 스타일시트에만 있어 작성자 규칙에 항상 지기 때문이다.

jsdom은 이 우선순위를 실제 브라우저와 다르게 처리해 **거짓 통과**시킨다. 그래서 `css.test.js`는 CSS 원문을 직접 검사한다.

## 출처

종 사전은 로컬 식물 비교도감(`plant_atlas`) 색인에서 추출했다. 국명·학명·이명·과 정보를 포함하며, 법정보호종 여부는 **포함하지 않는다** — 별도 확인이 필요하다.

식생조사 층위 구분은 국립생태원 자연환경조사 지침의 4층 체계를, 우점도는 Braun-Blanquet 척도를 따랐다. 흉고직경은 지상 1.2m 기준이다.
